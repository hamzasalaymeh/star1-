# 🌟 جهاز تصدير جداول منصة STAR1 الأوتوماتيكي

أداة قوية لتصدير جداول البيانات من منصة STAR1 إلى ملفات PDF تلقائياً، مع تسجيل دخول خلفي وتحميل كامل البيانات من 3000+ استمارة.

## ✨ المميزات

- ✅ تسجيل دخول أوتوماتيكي في الخلفية
- ✅ إدخال رقم قرار التسجيل تلقائياً
- ✅ فتح الاستمارات من القائمة (3000+ استمارة)
- ✅ الانتقال تلقائي إلى قسم "معايير التصنيف"
- ✅ استخراج الجدول المحدد بالمربع الأحمر فقط
- ✅ تحميل كامل البيانات
- ✅ تصدير PDF عالي الجودة
- ✅ لقطات شاشة للتحقق
- ✅ معالجة دفعات من القرارات
- ✅ إعادة محاولة تلقائية عند الفشل

## 📋 المتطلبات

- Node.js 14+
- npm أو yarn
- بيانات دخول صحيحة للمنصة

## 🚀 التثبيت

```bash
npm install
```

## 🔄 خطوات العملية

1. **تسجيل الدخول** - تسجيل دخول أوتوماتيكي في الخلفية
2. **إدخال رقم القرار** - إدخال رقم قرار التسجيل المطلوب
3. **فتح الاستمارات** - فتح كل استمارة من القائمة
4. **الانتقال إلى التصنيف** - الذهاب تلقائياً إلى قسم "معايير التصنيف"
5. **استخراج الجدول** - الحصول على الجدول المحدد بالمربع الأحمر
6. **التصدير** - تصدير الجدول كـ PDF ولقطة شاشة

## 💻 طرق الاستخدام

### 1️⃣ الطريقة التفاعلية (الأسهل)

```bash
node exporter-cli.js
```

سيطلب منك:
1. اسم المستخدم
2. كلمة المرور
3. أرقام قرارات التسجيل المراد معالجتها (مثال: 21، 22، 23)

### 2️⃣ البرمجية

```javascript
const AdvancedTablePDFExporter = require('./table-pdf-exporter-advanced');

const exporter = new AdvancedTablePDFExporter('username', 'password');

const results = await exporter.run([
  { name: 'قرار_ترشيح_1' },
  { name: 'قرار_ترشيح_2' },
  { name: 'قرار_ترشيح_3' },
]);

console.log(results);
```

### 3️⃣ من سطر الأوامر

```bash
node table-pdf-exporter-advanced.js username password
```

## 🎯 ميزات متقدمة

### تخصيص الإعدادات

```javascript
const exporter = new AdvancedTablePDFExporter('username', 'password', {
  baseUrl: 'https://heritage2.itqan-consultant.com/Web/App/Pools/DataEdit/19112/10',
  outputDir: './exports',
  headless: true,
  navigationTimeout: 30000,
  maxRetries: 3,
});
```

### معالجة القرارات بـ URLs مختلفة

```javascript
const decisions = [
  { 
    name: 'قرار_1',
    url: 'https://..../19112/10' // URL اختيارية لكل قرار
  },
  { 
    name: 'قرار_2',
    url: 'https://..../19112/11'
  },
];

const results = await exporter.run(decisions);
```

## 🔧 استكشاف الأخطاء

### المشكلة: "لم يتم العثور على الجدول"
- تأكد من تسجيل الدخول الصحيح
- تحقق من URL المنصة
- جرب مع `headless: false` للرؤية الفعلية

### المشكلة: "فشل تسجيل الدخول"
- تحقق من بيانات الدخول
- قد تحتاج المنصة لـ 2FA أو توثيق إضافي

### المشكلة: "انتهاء المهلة الزمنية"
- زيادة `navigationTimeout`
- تحقق من سرعة الإنترنت
