# 🏛️ أتمتة منصة اكتشاف وتسجيل أصول التراث العمراني

## 📋 نظرة عامة

هذا السكريبت يقوم بأتمتة تحديث 5256+ موقع بتغيير المنطقة إلى "المنطقة الجنوبية" على منصة التراث العمراني.

**المميزات:**
- ✅ Headless Mode (شغل في الخلفية بدون نافذة)
- ✅ نظام Checkpoint للاستئناف من آخر نقطة
- ✅ Database SQLite لتتبع حالة كل موقع
- ✅ تقرير Excel مفصل جداً
- ✅ معالجة أخطاء قوية
- ✅ لا تعارضات مع عملك اليدوي

## 🚀 التثبيت والإعداد

### 1️⃣ تثبيت المكتبات المطلوبة

```bash
pip install -r requirements.txt
```

أو يدوياً:

```bash
pip install selenium==4.15.2 pandas==2.1.3 openpyxl==3.1.2 webdriver-manager==4.0.1
```

### 2️⃣ تحميل ChromeDriver

السكريبت سيحمل ChromeDriver تلقائياً، لكن تأكد من وجود Chrome/Chromium مثبت على الجهاز.

### 3️⃣ ضبط بيانات الدخول (مهم جداً 🔐)

**لا تكتب اليوزر والباسورد داخل الكود أبداً** — بيصير جزء من تاريخ الـ git ويصعب حذفه لاحقاً حتى لو عدّلته بعدين.

بدلها، اضبطهم كمتغيرات بيئة قبل التشغيل:

```bash
export HERITAGE_USERNAME='M.sobhy'
export HERITAGE_PASSWORD='xxxxxx'
python heritage_automation.py
```

أو أنشئ ملف `.env` (هو مُستثنى من git تلقائياً عبر `.gitignore`) وحمّله بأداة مثل `python-dotenv`، أو ببساطة شغّل الأمرين أعلاه في نفس الجلسة (Terminal) قبل تشغيل السكريبت.

## ⚙️ الإعدادات القابلة للتعديل

في بداية `heritage_automation.py`:

```python
BASE_URL = "https://heritage2.itqan-consultant.com/Web/"
USERNAME = "M.sobhy"
PASSWORD = "846448"
TARGET_REGION = "المنطقة الجنوبية"
REGION_FIELD_NUMBER = 4

HEADLESS = True          # True = بدون نافذة، False = نافذة مرئية
IMPLICIT_WAIT = 10      # انتظار عام
EXPLICIT_WAIT = 20      # انتظار عناصر محددة
```

## 🔍 ماذا تفعل الأتمتة بالضبط؟

لكل موقع:

1. **فتح الموقع** 📂
   - ينقر على رابط الموقع

2. **الانتقال إلى بيانات المعماري** 🏗️
   - ينقر على التاب "بيانات المعماري"

3. **تحديث المنطقة** 🗺️
   - يجد حقل المنطقة رقم 4
   - يختار "المنطقة الجنوبية"
   - إذا كانت مختارة بالفعل → يتخطى (skipped)

4. **حفظ البيانات** 💾
   - ينقر على زر الحفظ
   - ينتظر رسالة النجاح

5. **الانتقال للموقع التالي** 🔄

## ⚠️ حل مشاكل شائعة

### المشكلة: "Timeout waiting for element"
**الحل:** زيادة `EXPLICIT_WAIT` من 20 إلى 30 أو 40

### المشكلة: "المتصفح لا يفتح"
**الحل:** 
- تأكد من تثبيت Chrome
- حاول تشغيل مع `HEADLESS = False` لرؤية المشكلة

### المشكلة: "فشل تسجيل الدخول"
**الحل:**
- تحقق من اسم المستخدم وكلمة المرور
- تأكد من أن الموقع يعمل
- حاول يدوياً أولاً

### المشكلة: "الأتمتة بطيئة جداً"
**الحل:**
- هذا طبيعي (كل موقع ~3-5 ثوان)
- الاستراتيجية: اترك الكود يعمل بالخلفية
