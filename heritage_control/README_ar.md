# 🏛️ مركز تحكم أتمتة مشروع التراث العمراني

برنامج Windows واحد يجمع كل أتمتات المنصة في **واجهة واحدة**: تختار الأتمتة،
تضبط إعداداتها، تضغط **ابدأ**، وتتابع التقدّم وتتحكم (إيقاف مؤقت / استئناف /
إيقاف آمن) من نفس النافذة — بدون فتح أكواد أو CMD.

> المؤلف: ENG. Hamza ALsalaymeh

---

## 1) التثبيت (مرة واحدة)
```
pip install -r requirements.txt
python -m playwright install chromium      (فقط لأتمتات التصدير PDF/الصور)
```
> الواجهة تستخدم **Tkinter** المدمج مع بايثون على ويندوز (لا يحتاج تثبيت).

## 2) التشغيل
```
python app.py
```
تفتح النافذة. اضغط بطاقة الأتمتة → اضبط الإعدادات → **ابدأ**.

---

## 3) ما الذي يميّزه (مش Launcher)
- **محرّك حقيقي:** يشغّل الأتمتة كعملية فرعية، يقرأ تقدّمها لحظياً، ويتحكم بها
  عبر ملف تحكم — الأزرار متصلة فعلاً بالمحرّك.
- **تحكم كامل:** ابدأ / إيقاف مؤقت / استئناف / **إيقاف آمن** (لا يقطع وسط حفظ).
- **مراقبة حيّة:** الكل / نجح / فشل / متبقّي / النسبة / الموقع الحالي / متوسط
  زمن الموقع / الزمن المنقضي / سجل ملوّن مباشر.
- **لا تتجمّد الواجهة** أثناء Selenium/Playwright (تسحب الأحداث عبر مؤقّت).
- **استئناف:** كل أتمتة تكمل من مكان التوقّف وتعيد الفاشل فقط.
- **ثيم فاتح/داكن + RTL**، ويتذكّر آخر إعداداتك + ملفات تعريف (Presets).
- **نظام Plugins:** كل أتمتة وحدة مستقلة؛ أي وحدة جديدة تظهر تلقائياً.

---

## 4) الأتمتات المتوفّرة
تُكتشف تلقائياً من مجلد `plugins/`. حالياً:
`📜 الأوصاف التاريخية` · `🗺️ الكروكي + X/Y + المساحة` · `📐 التكميلي` ·
`🏛️ تعديل الطراز المعماري` · `📸 تصدير ملفات المواقع (3 PDF + صور)` ·
`📄 تصدير جداول التصنيف` · `🧹 متابعة الفاشلين`.

**شارة البطاقة:**
- `● تحكم كامل` = إيقاف/استئناف حقيقي + شريط تقدّم (حالياً: الأوصاف التاريخية).
- `○ سجل حيّ` = يعمل ويُعرض سجله الحيّ، وقابل للاستئناف، والإيقاف يُغلق التشغيل
  (تُضاف له أزرار الإيقاف/الاستئناف الكاملة في التحديثات القادمة).

## 5) بناء ملف EXE (أيقونة سطح مكتب)
على جهاز التطوير (ويندوز):
```
pip install pyinstaller
pyinstaller heritage_control.spec
```
الناتج: `dist/HeritageControl/HeritageControl.exe` — انسخ المجلد كاملاً، وأنشئ
اختصاراً للـexe على سطح المكتب.
> ملاحظة: متصفح Playwright لا يُجمَّع داخل الـexe؛ شغّل مرة
> `python -m playwright install chromium` على الجهاز لأتمتات التصدير.

## 6) إضافة أتمتة جديدة مستقبلاً
1. ضع سكربت الأتمتة في `scripts/`.
2. أنشئ ملفاً `plugins/p_اسمك.py` فيه:
```python
PLUGIN = {
    "id": "my_task", "order": 10,
    "title": "اسم الأتمتة", "desc": "وصف مختصر", "help": "شرح",
    "script": "my_task.py",
    "argv_prefix": [],            # وسائط ثابتة قبل الإعدادات
    "supports_control": True,     # True لو فيها hooks الإيقاف/التقدّم
    "emits_progress": True,
    "settings": [                 # حقول تظهر بالواجهة وتُمرَّر للسكربت
        {"name": "region", "label": "المنطقة", "type": "choice",
         "choices": ["عسير"], "arg": "--region"},
    ],
}
```
3. (للتحكم الكامل) في سكربتك: `from agent_runtime import R` ثم نادِ
   `R.total(n)` / `R.progress(done=..,failed=..,current=..)` /
   `R.wait_if_paused()` و `R.should_stop()` عند نقاط آمنة (قبل كل موقع).
4. سجّل الاسم في `plugins/registry.py` قائمة `_KNOWN` (ليعمل بعد تجميع EXE).

تظهر الأتمتة تلقائياً في الواجهة — بدون تعديل الواجهة الرئيسية.

## 8) ما تم اختباره فعلياً مقابل ما يحتاج اختباراً على المنصة
**مُختبَر فعلياً (آلياً، بدون منصة):**
- المحرّك: التشغيل والتقدّم الحيّ والإيقاف المؤقت والاستئناف والإيقاف الآمن.
- الواجهة: بناء كل الشاشات، وقيادة تشغيل حقيقي عبر الأزرار، وتحديث العدّادات.
- اكتشاف الـPlugins وبناء أوامر التشغيل وتمرير بيانات الدخول.
- آلية تشغيل السكربتات (تعمل كـpython وكـEXE).

**يحتاج اختباراً على جهازك ضد المنصة الحيّة:**
- سلوك كل أتمتة فعلياً على المنصة (تسجيل الدخول، المعالجة، الحفظ) — لأنه يعتمد
  على المتصفح والجلسة والمنصة، ولم تُنفّذ أي كتابة فعلية على المنصة أثناء التطوير.
- ربط التقدّم/الإيقاف الكامل لبقية الأتمتات (غير الأوصاف التاريخية) — مجدول
  للتحديث القادم.

## 9) ملاحظات أمان واستقرار
- **كلمة المرور لا تُحفظ على القرص** — تبقى في النافذة فقط وتُمرَّر للعملية.
- البرنامج **لا يغلق كل نوافذ Chrome** — يدير جلسته فقط (حسب كل أتمتة).
- الحالة (آخر إعدادات/Presets/الثيم) محفوظة في `~/.heritage_control_state.json`.
