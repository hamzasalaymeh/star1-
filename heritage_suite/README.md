# 🏛️ مجمّع أتمتة مشروع التراث العمراني

تطبيق واحد يجمع كل أتمتات منصة التراث في **نافذة واحدة** — تختار الأتمتة،
يسألك عن المنطقة/القرار/القرى/المجلد (لا شيء محفور)، ويشغّلها.

> المؤلف: ENG. Hamza ALsalaymeh

---

## التشغيل (ويندوز)

1. ثبّت المتطلبات مرة واحدة:
   ```
   pip install -r requirements.txt
   python -m playwright install chromium      (فقط لو رح تستخدم تصدير PDF)
   ```
2. شغّل المجمّع:
   ```
   python hub.py
   ```
3. تفتح النافذة — اضغط الأتمتة اللي بدك، عبّي المطلوب، واضغط «تشغيل».
   بتفتح نافذة طرفية فيها تقدّم العمل.

**نصيحة:** سكّر ملف الإكسل قبل أي تشغيل حتى يقدر يحفظ النتائج.

## الأتمتات (النسخة الأولى)

| الزر | الوظيفة | يسألك عن |
|------|---------|----------|
| 📜 الأوصاف التاريخية | يكتب الوصف التاريخي لكل مبنى | المنطقة + (قرارات/قرى/أكواد) + وضع مرن + معاينة |
| 🗺️ الكروكي + X/Y + المساحة | يرفع صورة الكروكي ويكتب الإحداثيات والمساحة | مجلد القرى + رقم القرار (بنوافذه) |
| 📐 التكميلي | إحداثيات المضلّع + ارتفاع/مطار/مسافة | مجلد القرى + البيانات (بنوافذه) |
| 🏛️ تعديل الطراز المعماري | يحدّث الطراز لكل مواقع منطقة/خطوة | المنطقة + الطراز المستهدف + حد التجربة |
| 📄 تصدير PDF | يصدّر استمارات قرار إلى PDF + فهرس Excel | رقم القرار + عدد الاستمارات |

## مميزات إضافية
- 🔁 **استئناف ذكي لكل أتمتة:** لو توقّفت وأعدت التشغيل تكمل من مكانها، وتعيد الفاشل فقط.
- 🧹 **زر «متابعة الفاشلين»:** يمسح مجلد التقارير ويجمع كل الأكواد الفاشلة/المتخطّاة بقائمة جاهزة + Excel.
- 💾 **يتذكّر آخر إعداداتك** لكل أتمتة + **ملفات تعريف (Presets)** تحفظها بأسماء.
- ❓ زر «؟» شرح جنب كل أتمتة.
- 🧪 اختبارات تلقائية في `tests/` (`python tests/test_suite.py`).
- 📌 نسخ مثبّتة بـ `requirements-lock.txt` لتفادي الكسر المفاجئ.

## ملاحظات
- بيانات الدخول تُدخَل في النافذة مرة واحدة (معبّأة مسبقاً) وتُمرَّر للعملية — **لا تُحفظ على القرص**.
- كل أتمتة تحتفظ بنقاط استئنافها وتقاريرها كما في نسختها الأصلية.
- أتمتات (الكروكي/التكميلي) تفتح Chrome الخاص بها وتطلب تسجيل الدخول أول مرة.
- أتمتات قادمة (نسخ لاحقة): تصدير الصور، التحويل الدفعي، أدوات أخرى.
