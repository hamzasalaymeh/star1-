   آلية تشغيل أداة تصدير جداول معايير التصنيف - PDF
════════════════════════════════════════════════════════

آخر تحديث: 13 أغسطس 2026


────────────────────────────────────────
1) الملفات المطلوبة (لازم تكون كلها بنفس المجلد)
────────────────────────────────────────

- table_pdf_exporter_advanced.py     ← المكتبة الأساسية (لا تشغّله مباشرة)
- run_decision_export.py             ← سكربت التشغيل الفعلي (هذا اللي بتشغّله)
- test_first_10.py                   ← سكربت تجربة سريعة (اختياري)
- inspect_page.py                    ← أداة فحص احتياطية لو صار خطأ غريب
- requirements_python.txt            ← قائمة المكتبات المطلوبة


────────────────────────────────────────
2) التثبيت (مرة وحدة بس، أول استخدام)
────────────────────────────────────────

افتح "Windows Terminal" (وليس cmd.exe التقليدي - راجع ملاحظة مهمة بالأسفل)
بنفس مجلد الملفات، واكتب:

    pip install -r requirements_python.txt
    playwright install chromium

انتظر لحد ما يخلص التثبيت.


────────────────────────────────────────
3) طريقة التشغيل
────────────────────────────────────────

الصيغة العامة:

    python run_decision_export.py <رقم_القرار> [عدد الاستمارات] [اسم_المستخدم] [كلمة_المرور]

أمثلة:

  أ) تجربة صغيرة (أول 10 استمارات فقط) - جرّب هيك أول مرة دايماً:
     python run_decision_export.py 21 10

  ب) تجربة أكبر تتأكد فيها إن التنقل بين صفحات النتائج شغال صح
     (لازم يتجاوز أول صفحة نتائج، اللي فيها عادة 25 رابط):
     python run_decision_export.py 21 60

  ج) التشغيل الكامل - يصدّر كل استمارات القرار (بدون تحديد عدد):
     python run_decision_export.py 21

  د) لو بدك تمرر اسم المستخدم وكلمة المرور مباشرة بالأمر (غير مستحسن،
     الأفضل تتركهم فاضيين ويسألك السكربت وقت التشغيل):
     python run_decision_export.py 21 10 اسم_المستخدم كلمة_المرور

بعد ما تشغّل الأمر، السكربت رح يسألك:
    👤 اسم المستخدم:
    🔑 كلمة المرور:      (مخفية، ما بتظهر وأنت تكتبها)


────────────────────────────────────────
4) وين بتلاقي النتائج
────────────────────────────────────────

كل قرار بياخذ مجلد خاص فيه:

    exports/
      └── قرار_21/
            ├── فهرس_قرار_21.xlsx          ← ملف Excel فيه كل المواقع
            │                                 مع رابط "فتح الملف" لكل PDF
            ├── اسم_الموقع_1/
            │     ├── اسم_الموقع_1.pdf
            │     └── اسم_الموقع_1.png
            ├── اسم_الموقع_2/
            │     ├── اسم_الموقع_2.pdf
            │     └── اسم_الموقع_2.png
            └── ...

ملاحظة مهمة عن ملف Excel:
روابط الـ PDF بداخله "نسبية" (relative) مش مسار ثابت - يعني تقدر
تنقل مجلد exports كامل (بكل المجلدات الفرعية اللي جواه) لأي جهاز
أو فلاشة أو مسار تاني، وروابط الإكسل بتضل شغالة طالما نقلت المجلد
كامل مع بعضه ومارتبتش الملفات من جوا.


────────────────────────────────────────
5) الوقت المتوقع
────────────────────────────────────────

- استمارة وحدة: تقريباً 3-6 ثواني
- 3000 استمارة: ممكن تاخذ من 3 إلى 5 ساعات تقريباً
  (خليها تشتغل لحالها، بلا ما تلمس الجهاز أو تقفل الطرفية)


────────────────────────────────────────
6) ملاحظات مهمة جداً
────────────────────────────────────────

⚠️ الأمان:
  - لا تكتب اسم المستخدم أو كلمة المرور بأي محادثة أو رسالة أبداً
  - اكتبهم بس لما السكربت يسألك عنهم مباشرة بالطرفية

⚠️ الطرفية (Terminal):
  - استخدم "Windows Terminal" مش cmd.exe التقليدي الأسود
  - لو مش موجود عندك، حمّله من Microsoft Store (مجاني)
  - cmd.exe التقليدي بيقلب اتجاه الكتابة العربي وما بيطلّع الألوان صح

⚠️ لو ظهرت رسالة خطأ "لم يتم العثور على..." أو أي مشكلة تسجيل دخول:
  - جرّب أداة الفحص: python inspect_page.py
  - رح تفتح متصفح ظاهر وتطلعلك تفاصيل الصفحة، ابعتها للمطوّر

⚠️ headless:
  - السكربت الرئيسي (run_decision_export.py) بيشتغل بالخلفية بدون
    ما يفتح متصفح ظاهر (أسرع بكثير)
  - لو بدك تراقب المتصفح وهو شغال، افتح الملف وغيّر:
    'headless': True   →   'headless': False


────────────────────────────────────────
7) خطوات سريعة (تلخيص)
────────────────────────────────────────

1. افتح Windows Terminal بمجلد الملفات
2. (أول مرة بس) pip install -r requirements_python.txt
3. (أول مرة بس) playwright install chromium
4. python run_decision_export.py <رقم القرار> <عدد الاستمارات>
5. اكتب اسم المستخدم وكلمة المرور لما يسألك
6. انتظر لحد ما يخلص
7. افتح exports/قرار_<الرقم>/فهرس_قرار_<الرقم>.xlsx وتأكد من النتائج
